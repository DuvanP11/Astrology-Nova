# Inherited skills

These came from Sky Map v2 and are kept because they describe *this* code's build and data
workflows accurately.

Four were deleted rather than inherited, because they act on Sky Map's own accounts and would
have pointed a future session at someone else's Play Store listing, credentials and users:
`skymap.deploy-play-store`, `skymap.release`, `skymap.respond-reviews` and
`skymap.sync-credits`.

The remaining skills still say "Sky Map v2" and reference the module as `stardroid-v2/`; here
it is `android/`. Read them with that substitution in mind.
