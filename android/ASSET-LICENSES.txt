# Astrology Nova — asset licence manifest
#
# THE AUTHORITATIVE LIST of which non-code assets are proprietary and which are not.
# `LICENSE.md` reserves rights over the files listed under [arr] and nothing else.
#
# Enforced by `tools/check_asset_licenses.py`, which runs in CI, in both directions:
#   - every asset under `app/src/main/res/` and `app/src/main/assets/` must match a rule
#     below, so a new file cannot ship unclassified;
#   - every rule below must match a shipped file, so a claim cannot outlive the asset it
#     described.
# Adding or removing an asset means editing this file in the same commit - that build
# failure is the reminder.
#
# FORMAT
#   [section]     one of: arr, gpl, apache-v1, third-party
#   one glob per line, relative to app/src/main/
#   '#' starts a comment; blank lines ignored
#   First matching rule wins, so order matters within and between sections.
#
# WHEN ADDING AN ASSET, ask: did we draw it, and is it brand?
#   yes / yes  -> [gpl]           this fork reserves nothing; see the note below [arr]
#   yes / no   -> [gpl]           functional artwork, ships under GPLv3 like the code
#   no, v1     -> [apache-v1]     Apache-2.0 from v1; check NOTICE.md for who owns it
#   no, extern -> [third-party]   NASA/ESA/etc, under its own terms — NOT ours
#
# The expensive mistake here is misfiling someone else's work as ours. When unsure about a
# file's provenance, put it in [third-party] and record where it came from.


# THERE IS NO [arr] SECTION IN THIS FORK, AND THAT IS DELIBERATE.
#
# Upstream reserved rights over its brand artwork — the launcher icon, the notification
# glyph, the onboarding backdrop and the sky-marker set — so that a clone could not pass
# itself off as Sky Map. That claim was theirs to make and it is not inherited: none of
# those files survive here. Every one was replaced with artwork drawn for Astrology Nova,
# and all of it ships under the GPLv3 like the code, because reserving rights over it would
# buy this project nothing and would obstruct the next fork for no gain.
#
# If you are diffing against upstream and looking for its reserved files, they are gone:
#   res/drawable/ic_launcher_{background,foreground,monochrome}.xml   redrawn (Nova mark)
#   res/mipmap-anydpi-v26/ic_launcher{,_round}.xml                    redrawn
#   res/drawable/ic_stat_skymap.xml                                   redrawn
#   res/drawable-nodpi/welcome_sky_bg.webp   regenerated, tools/generate_welcome_bg.py
#   assets/catalog/icons/*.webp              regenerated, tools/generate_marker_icons.py
